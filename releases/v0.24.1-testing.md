# WeaverDeck v0.24.1 runtime test record

Documentation recorded 2026-09-22 from the user's existing completion feedback.
This date records the documentation update, not a new hardware test.

## Confirmed on the existing Stream Deck XL / CachyOS setup

- The user confirmed that the icon change worked.
- The user confirmed that Scene descriptive text was gone and all controls still worked.
- The user also confirmed that the wiki appeared to have updated correctly.

The later question about missing dial actions was resolved by explaining that
dial operations are part of the grouped actions and are selected automatically
when assigned to encoders. It was not a report of failed XL controls.

## Scope and remaining testing

These confirmations supplement the [v0.23.0 grouped-action record](v0.23.0-testing.md)
and [v0.24.0 Scene-preview record](v0.24.0-testing.md). They record the user's
reported checks, not a new exhaustive regression run.

packaging validation. No separate user runtime check of verbose logging is claimed.

Non-XL hardware, dial and touch-strip testing remains intentionally outstanding
until suitable testers are available. It is not a defect or blocker for the
finished Stream Deck XL scope. Other distributions and architectures retain the
status in the [compatibility matrix](../docs/COMPATIBILITY.md).
