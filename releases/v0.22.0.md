Configurable hold-repeat volume buttons, millisecond fades, persistent Scene Library, and compact action inspectors.

- Volume Up/Down actions support configurable Hold ms repeat speed.
- Standalone and Smart Scene fades use millisecond durations, with compatibility for older second-based settings.
- Saved Presets merge into one persistent Scene Library. Existing entries migrate without overwriting different same-name Scenes; Scene Files remains available for import/export.
- Action editors load directly in OpenDeck, fixing the recurring inspector clipping while retaining Dynamic Text, Manual Input and compact controls. Existing buttons navigate automatically from the old inspector path.
- Physical Input/Output fades wait for device feedback before advancing, avoiding premature confirmation failures without resending commands.
- The runtime is consolidated into plugin-core.js; historical patch files are removed while separate feature modules remain.

Validation: 71 automated tests pass. Runtime checks confirm Source A/B millisecond fades, immediate changes, Smart Scene ordering, restored durations, and C922/Volt 2 physical input fades, including concurrent fades. The user also confirmed the final inspector clipping fix.

Physical-device feedback can extend nominal fade durations. Scene file export/import is not independently established by the latest logs. See [the detailed test record](https://github.com/djbauer69/WeaverDeckPlg/blob/main/releases/v0.22.0-testing.md) for evidence and limits.
