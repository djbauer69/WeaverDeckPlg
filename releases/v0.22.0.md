# WeaverDeck v0.22.0

Configurable hold-repeat volume buttons, millisecond fades, persistent Scene Library and compact action inspectors.

- Volume Up/Down actions support configurable Hold ms repeat speed.
- Standalone and Smart Scene fades use millisecond durations, retaining compatibility with older second-based settings.
- Saved Presets merge into one persistent Scene Library without overwriting different same-name Scenes. Scene Files remains available for import/export.
- Action editors load directly in OpenDeck; existing buttons navigate automatically from the old inspector path.
- Inspector selection after deleting a button now triggers a brief repaint, including in short editors. Scroll positions/styles are restored, and lifecycle diagnostics are logged.
- Physical Input/Output fades wait for device feedback before advancing, avoiding premature confirmation failures without resending commands.
- The runtime is consolidated into plugin-core.js while separate feature modules remain.

Validation: **77 automated tests pass**. Runtime checks confirm Source A/B millisecond fades, immediate changes, Smart Scene ordering, restored durations and C922/Volt 2 physical input fades, including concurrent fades. The user confirmed the deletion/reselection inspector fix on 7 September 2026.

Physical-device feedback can extend nominal fade durations. Scene file export/import is not independently established by the latest fade logs. See the [detailed test record](https://github.com/djbauer69/WeaverDeckPlg/blob/main/releases/v0.22.0-testing.md).
