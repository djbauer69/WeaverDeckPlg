# WeaverDeck v0.23.0 — grouped actions (review build)

Six grouped actions replace 51 individual sidebar entries: Application, Physical Input, Physical Output, Route, Source and Target. Select the operation from the inspector header; all existing operation handlers remain available. Together with six unchanged utilities, the sidebar now contains 12 alphabetically sorted entries.

Physical Input and Output gain device icon selectors with six input and four output designs, plus Default. Physical mute icons show live/muted status; volume artwork keeps its current percentage badge. Dynamic/Manual Text, hold settings, millisecond fades, Smart Scenes and the inspector visibility recovery remain supported.

**Existing installations must use the offline migration/installer before opening OpenDeck with this build.** It backs up and converts saved profiles, including nested Multi Actions, then installs the checksum-verified ZIP. See [the upgrade guide](../docs/UPGRADE-v0.23.0.md) for commands, rollback and older profile import limitations.

Validation: **87 Node tests and 15 Python tests pass**. New checks cover every grouped operation mapping, runtime dispatch, invalid selections, held-control cancellation, fade resource/duration handling, inspector operation switching, shared text preferences, custom artwork, all legacy UUID conversions, backups and rollback. ZIP contents and executable modes are verified against source. Actual OpenDeck/PipeWeaver review of this build is pending.

This is a review build; v0.22.0 remains the stable release.

Installer follow-up: recognize root-level OpenDeck device-selection metadata separately from button profiles, preserving it unchanged. Validation errors now include the affected file path. Three regression tests cover metadata preservation and continued rejection of malformed profiles. The plugin ZIP and checksum are unchanged.
