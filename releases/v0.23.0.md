# WeaverDeck v0.23.0

Six grouped actions replace 51 individual sidebar entries: Application, Physical Input, Physical Output, Route, Source and Target. Select an operation from the inspector header. Together with the six utility actions, the sidebar now contains 12 alphabetically sorted entries.

Physical Input and Output gain six input and four output icon choices, plus Default. Mute icons show live/muted state; volume artwork retains the current percentage badge. Dynamic/Manual Text, hold settings, millisecond fades, Smart Scenes and inspector visibility recovery remain supported. Original Route, Target Mix and Target Mute icons are restored.

**Validation:** 89 Node tests and 15 Python tests pass. On 7 September 2026, the user confirmed all requested grouped-action runtime checks passed. The supplied log contains nine completed fades and three cancellations consistent with interruption tests, with no crashes or timeout errors. See the [detailed test record](https://github.com/djbauer69/WeaverDeckPlg/blob/main/releases/v0.23.0-testing.md).

Install `pipeweaver-opendeck-plugin-v0.23.0.zip` directly through OpenDeck on fresh installations or profiles already migrated to v0.23.0. Profiles still using older individual action identifiers need the [one-time migration](https://github.com/djbauer69/WeaverDeckPlg/blob/main/docs/UPGRADE-v0.23.0.md) first. Subsequent updates on the migrated setup use only the plugin ZIP.
