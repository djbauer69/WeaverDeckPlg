# WeaverDeck v0.24.0 — Scene preview (review build)

Adds Preview Scene beside Validate Scene in the Scene inspector. Expand each step to inspect resolved selections, before/after values, conditions, failure policy and missing/ambiguous resources. Earlier direct changes are projected forward; unknown linked-mix effects and later state after timed/engine steps are marked provisional.

Preview reads PipeWeaver status only. It does not execute Scene operations, change audio settings, wait through delays or restart the engine. Editing the Scene invalidates the result; request correlation prevents late replies from showing an old Scene.

All v0.23.0 grouped actions, icons, volume controls, Scenes and inspector fixes are retained. Install the plugin ZIP directly through OpenDeck on the existing v0.23.0 setup.

Validation: 98 Node tests pass, including a 38-step fixture based on the user's Default Scene with physical identifiers anonymized. Read-only dispatch, state projection, all operation families, conditions, offline/ambiguous selections and stale UI responses are covered. Runtime confirmation is pending.
