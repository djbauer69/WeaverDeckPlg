# WeaverDeck

WeaverDeck connects OpenDeck controls to PipeWeaver on Linux. The current version is **v0.22.0**.

- [Actions](https://github.com/djbauer69/WeaverDeckPlg/wiki/Actions) — all 57 actions, settings, Scenes, files, startup and fade behavior.
- [Version History](https://github.com/djbauer69/WeaverDeckPlg/wiki/Version-History) — changes from the earliest recorded versions through v0.22.0.
- [Communication](https://github.com/djbauer69/WeaverDeckPlg/wiki/Communication) — OpenDeck events, PipeWeaver commands, state storage and diagnostics.
