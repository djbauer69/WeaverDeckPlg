# WeaverDeck

WeaverDeck connects OpenDeck controls to PipeWeaver on Linux. The current version is **v0.24.1**.

- [Actions](https://github.com/djbauer69/WeaverDeckPlg/wiki/Actions) — 12 sidebar actions and all 57 operations, settings, Scene preview, files, startup, fades and icon choices.
- [Version History](https://github.com/djbauer69/WeaverDeckPlg/wiki/Version-History) — changes from the earliest recorded versions through v0.24.1.
- [Communication](https://github.com/djbauer69/WeaverDeckPlg/wiki/Communication) — OpenDeck events, PipeWeaver commands, state storage and diagnostics.
