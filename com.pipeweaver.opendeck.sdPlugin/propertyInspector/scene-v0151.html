Scene Library — persistent native Scenes shared by every WeaverDeck Scene action. Loading copies the selected library Scene into this button, so it remains deterministic even if the library entry changes later.
Capture Scope — choose which categories Capture Current State should include. All remain enabled by default.
Scene Files — save/load portable WeaverDeck Scene files. Save writes directly to your Linux Downloads folder and reports the exact path.
Browser-local Presets — retained for compatibility with v0.14.x. Prefer Scene Library for persistent reusable Scenes.
