Connecting…
This is one shared startup setting for the plugin. Save applies it to the next OpenDeck/plugin launch. The plugin waits for PipeWeaver, validates the saved Scene, then runs it once. Reconnecting does not run it again. Disabling and saving cancels a pending startup run.
The file is read from disk at each launch. Keep it at this path. Press this deck button to run the saved file manually. It works even if startup is disabled.
Engine readiness does not mean every application is playing audio. A short delay can help applications appear, but absent application steps retain their normal skip behaviour. Scenes containing engine restarts may require you to resume playback manually.
